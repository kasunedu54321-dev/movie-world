# Movie World v2

## Included
- Responsive movie library
- Search and genre filters
- Movie player modal
- Authorized-download link
- Local browser admin form
- LocalStorage persistence

## Run
Open `index.html` in a browser.

## Put it online
Upload the three files (`index.html`, `style.css`, `app.js`) to a static hosting service.

## Important
This is a front-end demo. The admin panel is NOT secure and only changes movies in the current browser. For a real public service, use a backend such as Firebase/Supabase and server-side authentication/rules.

Only host movies, posters, and downloads that you own or are licensed to distribute.
